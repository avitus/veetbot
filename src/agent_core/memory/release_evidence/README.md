# Provider-memory release evidence

Reviewed evidence generated by `agent eval memory-formation` or
`agent eval memory-distillation` may be bundled here by release engineering.
The runtime loads only `*.json` files and requires an exact extractor,
formation-policy, model-policy, provider, model, policy-profile, and compiled-
policy-version match.

`openai-balanced-gpt-5.6-sol-default-formation9.json` is the active comparative
evidence for Nemori-assisted `formation@9`, the `balanced` model policy, the
`default` profile, and OpenAI `gpt-5.6-sol`. It passed the 61-case formation-v3
corpus with 100 percent direct must-form recall, 100 percent hypothesis
must-form recall, 96.875 percent benign precision, a 92.54 percentage-point
useful-recall lift over `formation@8`, and zero boundary failures. Automatic
selection activates it immediately for that exact tuple; startup scans all
matching `formation@9` evidence before considering an older artifact.

`openai-balanced-gpt-5.6-sol-default-formation8.json` remains as the frozen
provider-assisted control and fallback evidence. If no `formation@9` artifact
matches, automatic mode may select matching `formation@8` evidence; if neither
matches it records a content-free deterministic-fallback audit, while required
mode refuses startup.
